## 컨벤션 적응 사항

- TypeScript `JSON.stringify(value ?? null)` → Python `json.dumps(value, ensure_ascii=False)` (`None` → `"null"` 동일 동작)
- TypeScript `JSON.stringify([])` for `careerPool ?? []` → `json.dumps(data.career_pool if data.career_pool is not None else [], ensure_ascii=False)`
- 한국어 문자열에 `ensure_ascii=False` 적용 (가독성·토큰 절약)
- `_STAGE_CONFIG` dict에 `object` 타입 힌트 사용 (callable union 대신, mypy strict 대응 불완전하나 ruff 통과)
