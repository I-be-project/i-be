i-be Career Direction Pool — CURRENT FINAL
Base: Career Direction Pool v4.0 · 2026-10-01
Current use: Career Persona Prompt v17 기준 참고 사전

[현재 사용 원칙]
- 이 파일은 최종 직업 후보 목록이나 정답표가 아니라 Career Direction Dictionary다.
- Pair는 학생의 가치·태도·성격을 규정하지 않는다.
- 학생 개인의 가치·태도·Target·Desired Impact·Means는 반드시 Q1~Q9 원문에서 추출한다.
- work_modes / career_worlds / core_tasks는 현실적인 직업세계와 업무 연결을 확인하는 참고축이다.
- anchor_jobs / adjacent_roles / discovery_roles / student_aliases는 실제 직업명과 인접 역할을 탐색하기 위한 어휘 사전이다.
- 배열 순서는 추천도·적합도 순위가 아니다.
- Prompt v17에서는 Target + Desired Impact + Means가 충분히 특정 직업을 가리키면 구체적인 실제 직업까지 내려갈 수 있다.
- 반대로 Career Pool에 있는 직업이라고 해서 우선 선택하지 않으며, 근거가 부족하면 더 넓은 역할명에 머문다.
- Pool 밖 직업도 학생 원문과 Pair 방향으로 설명 가능하고 실제 존재하는 직업·직무라면 사용할 수 있다.

[Prompt v17 적용 시 사용 방식]
1. 학생의 Q1~Q9 원문에서 Value/Attitude · Target · Desired Impact · Means를 먼저 읽는다.
2. Pair의 work_modes / career_worlds / core_tasks는 이 역할 패턴이 연결될 수 있는 넓은 직업세계와 실제 업무를 확인하는 참고축으로만 사용한다.
3. anchor_jobs / adjacent_roles / discovery_roles / student_aliases는 직업명과 인접 역할을 탐색하는 어휘 사전으로 함께 참고한다. 순서에 우선순위는 없다.
4. Target + Desired Impact + Means가 특정 실제 직업의 업무와 충분히 겹치면 구체적인 직업까지 내려갈 수 있다.
5. 특정 분야까지 좁힐 근거가 부족하면 넓고 이해 가능한 실제 직무명에 머문다.
6. Pool 밖 직업도 학생 원문과 Pair 방향으로 설명 가능하고 실제 존재하거나 널리 쓰이는 역할이면 사용할 수 있다.
7. avoid_inference에 해당하는 관심·성격·능력을 Pair만으로 학생에게 덧씌우지 않는다.
8. 최종 Persona는 직업명을 먼저 고른 뒤 수식하는 방식이 아니라, 학생의 역할 패턴과 직업세계를 통합해 한 번에 생성한다.
