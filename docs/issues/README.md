## 새 기록 남기기

1. `docs/issues/YYYY-MM-DD-<한국어-슬러그>.md` 생성
2. 프론트매터(`date`·`kind`·`area`·`tags`·`commits`)와 본문 4섹션 작성
3. `python3 scripts/gen-docs-index.py` 실행해 이 표 갱신
